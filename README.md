# Bun Rush

This repository contains a simple one-page website for the **Bun Rush** brand. The site includes:

- `index.html` – the main page
- `style.css` – styling with warm retro colors
- `script.js` – a small script for the mobile navigation

To preview the site locally in your Codespace, run:

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000/` in the browser preview. Make sure to place `bun_rush_logo.png` in this folder if you have the logo image.
